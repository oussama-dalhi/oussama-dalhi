## Featured Projects

### [cViewer](https://github.com/oussama-dalhi/cViewer)

A lightweight image viewer written in C using SDL2 and stb_image.

**Highlights**
- Load and display images from the command line.
- Render images in an SDL2 window.
- Build and run using Make.
- Published [`releases`](https://github.com/oussama-dalhi/cViewer/releases).

**Tech:** C · SDL2 · Make · Linux

### [HTTP Server in C](https://github.com/oussama-dalhi/c-http-server)

A simple HTTP server built from scratch using Winsock on Windows, then ported and rebuilt for Linux using POSIX sockets.

**Highlights**
- TCP socket communication
- HTTP request parsing
- Static file serving
- Cross-platform implementation

**Tech:** C · Winsock · POSIX sockets · HTTP

### [YouTube Transcript Extractor](https://github.com/oussama-dalhi/youtube-transcript-extractor)

A full-stack application that extracts transcripts from YouTube videos.

**Tech:** Python · FastAPI · JavaScript

### [German Learning App](https://github.com/oussama-dalhi/de-learn-german)

A simple application for practicing German vocabulary and common phrases.

**Tech:** React · JavaScript

### [OBD-II Error Code Lookup](https://github.com/oussama-dalhi/obdcode-lockup)

A web application for looking up and understanding vehicle diagnostic trouble codes.

**Tech:** JavaScript · HTML · CSS
